# RTS6x handover, 2026-10-08 - RTS6x 1.1 in RIDE 5.1

Every number here was measured on the Windows PC, from fresh clones of each default branch
(C:\cxx1\rtsdiv); the Mac ran git, ssh and the seal tools.

## What changed

- **RTS6x 1.1** (rts6x-1.1.dat, 3346A221, 378 files): DecimalBinary without the padding work-round,
  since 5.0. Shipped in RIDE 5.1 (MASTER.SEAL 23D69F79).
- **tests/helpers/division.cpp** (da2c9ee): the reference divides by shift and subtract over the
  quotient's bits only - 355M to 132M cycles at -O0, 94M to 36M at -O2, the same 115,134 results.
  The reference itself agreed with cl's / and % on 34,348,126 pairs.
- **tools/speed** takes PREPARE=dir and FROM=dir, as tools/referee does, so the images are built on
  the Windows box and only shipped and judged from the Mac.
- The merged remote branch fix/drop-padding is deleted.

## How it was run, for the next time

- On the box, Git's shell with no host compiler cannot run c90's tests/tms6747.sh (its reference is a
  native build); c90's images were built directly - c90 -O2, asm6x, lnk6x with the suite's map - and
  `KEEP=1 PREPARE=dir tools/referee` collected both suites' images, `FROM=dir tools/referee` judged them.
- A Windows clone needs `core.autocrlf=false`, or every .expected differs by its line endings.
